The big idea

Context without clutter. Direction without pretending to schedule every minute.

Dandelion already knows the right level of detail: broad parts of a day. Relay makes each part immediately usable without turning it into another dense task list.

01 / NOW

A clear landing place

The first server-ordered action gets visual priority. Tap any On deck item to bring it forward—without changing Dandelion's data.

02 / VISIBLE

No tunnel vision

Overdue work, the queue, and other parts of the day stay in sight. Relay is hierarchy, not a hidden focus mode.

03 / FORGIVING

Act, then undo

Done, Cancel, and Move happen immediately. A short server-backed Undo replaces every “Are you sure?” dialog.

The product

One interaction language,
all day long.

Visible controls beat gesture trivia. The same Done, Move, and More actions appear on Today, projects, waiting items, and detail.

Trust by design

Native on the phone. Dandelion at the center.

Relay does not create a second source of truth. The Android app and today's web pages meet in shared Java services for the same filtering, completion, unblocking, notes, and sentence parsing.

1
Sign in, then approveNathan signs in on the S23, approves the named device in Dandelion on desktop, and receives a revocable per-device credential.
2
Own data, every timeThe server derives user and workspace from the approved device. IDs are always constrained to that scope.
3
Undo is realMutations return a short-lived server token that reverses the exact complete, cancel, or move—not a visual fiction.
Built to ship

A boring stack, on purpose.

Kotlin, Compose, Retrofit, DataStore, WorkManager, and the existing Jersey/Hibernate server. One repository. One app. Commands an agent can run.

AndroidAPI 28 minimum

Runs on Android 9 for the later Note8 student mode. Targets and compiles against API 36 for Nathan's S23 Ultra.

BuildGradle wrapper

.\gradlew.bat testDebug lintDebug assembleDebug
No global Gradle install.

Daily loopEmulator + S23

API 36 emulator for speed; the real phone for one-handed feel, Samsung notifications, and release acceptance.

InstallSigned APK via ADB

adb install -r app-release.apk
Updates preserve data with the stable package and signing key.
